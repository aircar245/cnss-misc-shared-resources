# 简介

共创的网页分享仓库。

## 我该怎么白嫖资源

打开 [resource.md](resource.md)，按分类展开即可查看资源卡片。

每张资源卡片固定展示三行：

1. 网站名称（可点击打开）
2. 网站或工具的一句话介绍。
3. 是否需要科学上网

## 我可以怎么做贡献

请前往 [Issues](../../issues) → New issue，并填写：

- 网站名称
- 网站网址
- 推荐分类（可使用“分类 > 子分类”继续细分）
- 一句话介绍
- 使用说明或学习资料链接（如有）
- 是否需要科学上网

请确保网址合法、安全、有实际价值。提交后由维护者审核，审核通过的资源会自动进入资源目录。
